# 灵感 AI · 中文在线工具平台

基于当前 `tz3558336-gif/codex-project` 个人网站原地升级，使用原生 HTML、CSS、JavaScript，无构建步骤，兼容 GitHub Pages 项目子路径。原有文件保留并更新。

## 能力与边界

| 工具 | 当前实现 |
| --- | --- |
| AI 文章生成器 | 主题、读者、风格、字数与要求表单；本地整理提示词、复制、导出接口请求 JSON。**尚未接入 API，不生成文章。** |
| 电商标题生成器 | 商品信息、卖点、平台、数量与长度表单；本地整理提示词、复制、导出请求 JSON。**尚未接入 API，不生成标题。** |
| 商品利润计算器 | 真实计算平台费用、利润、销售利润率、总成本与保本售价，支持 CSV 导出 |
| 批量文本处理 | 行首尾去空格、字面替换、大小写、移除空行、逐行去重、添加行号、字符/行数统计、复制和 TXT 下载 |
| AI 提示词管理 | 新增、编辑、删除、搜索、分类筛选、复制、JSON 导入/导出、重复条目跳过与本地持久化 |
| 用户中心 | 本地显示名称与工作方向、真实提示词/收藏数量、收藏入口、确认后清除平台本地数据 |

工具广场提供搜索、分类和工具收藏。页面使用 hash 路由，刷新子页面不需要服务器重写规则。没有账号认证、云同步、会员、支付、模拟余额或虚构 AI 结果。

### 利润计算规则

- 平台费用 = 售价 × 费率 / 100。
- 单件利润 = 售价 − 商品成本 − 运费 − 平台费用。
- 销售利润率 = 利润 ÷ 售价 × 100%，不是成本收益率。
- 保本售价 =（商品成本 + 运费）÷（1 − 费率 / 100）。
- 费率 100% 且成本/运费有正值时无法保本；成本和运费均为 0 时任意正售价均保本。
- 售价必须大于 0，其他金额非负，金额上限 10 亿元，费率 0–100%。金额精确到分，计算保留中间精度，结果显示两位小数。
- 这里只核算单件商品，不含广告、税费、退货等未输入支出。

### 本地数据与隐私

提示词、收藏、用户资料存储在当前站点的 `localStorage`，键为 `linggan-workspace-v1`。不同浏览器、设备、域名或隐私会话之间不会自动同步。GitHub Pages 同一域名下的其他项目可共享存储作用域，不要存放密钥或敏感资料。

默认没有任何 AI 网络请求；输入内容不会上传。页面仅引用本站静态资源，无外部字体/CDN。用户输入通过 `textContent` / 表单值渲染。剪贴板需要浏览器许可和安全上下文；不可用时提示手动复制。存储不可用、已满或原始数据损坏时显示警告，仍可处理文本、计算和导出当前数据，不会伪称保存成功。原始损坏数据不会被自动覆盖。

提示词最多 200 条，每条名称 100 字符、正文 20,000 字符；文本输入最多 200,000 个 UTF-16 字符。导入为合并操作，不覆盖已有提示词，相同名称/分类/内容的条目跳过。请定期导出备份，清理浏览器数据将删除本地记录。文本与计算输入只保留在当前页面内存中。

## 运行与访问

直接打开 `index.html` 即可使用本地功能。也可在项目目录启动服务器：

```bash
python3 -m http.server 8000
```

如果服务器运行在自己的电脑，可在同一台电脑访问 `http://localhost:8000`。如果服务器运行在 Codex 云端，Windows 的 localhost 无法访问它，必须使用平台实际提供的转发/预览入口或 GitHub Pages；启动服务器不会自动创建公网网址。

GitHub Pages 配置保持 **Deploy from a branch → main → / (root)**。`.nojekyll` 已保留。启用 Pages 且部署成功后的默认网址：

https://tz3558336-gif.github.io/codex-project/

## 文件

- `index.html`：工具广场、两个 AI 表单、利润计算、文本处理、提示词库和用户中心。
- `styles.css`：白色背景、紫色点缀的 SaaS 布局及手机/平板适配。
- `script.js`：路由、真实本地功能、数据存储及 AI 接口适配器。

- `package.json` / `package-lock.json`：仅用于开发测试，不是网站运行依赖。

## AI 后端接口预留

`script.js` 中的 `window.LingganAI.generate(request, { signal })` 提供 POST/JSON 响应适配器，默认 `endpoint: ''`，调用时明确抛出“尚未接入 AI API”。两个生成按钮保持禁用；本地整理提示词和下载请求不会调用该适配器。

导出的请求示例：

```json
{
  "tool": "article",
  "messages": [{ "role": "user", "content": "用户整理的提示词" }],
  "parameters": {
    "topic": "文章主题",
    "audience": "目标读者",
    "tone": "专业清晰",
    "length": "1000",
    "keywords": "补充要求"
  }
}
```

标题工具的 `tool` 为 `title`，参数为 `product`、`sellingPoints`、`platform`、`count`、`keywords`、`maxLength`。表单参数当前以字符串导出，后端应校验类型、范围、长度并做转换。成功响应约定为 `{ "text": "真实模型输出" }`；适配器处理非成功 HTTP 状态和无效响应结构。

未来接入时，在源码配置可信 HTTPS 后端 endpoint，增加认证/限流/超时/错误处理与加载状态，再连接按钮调用适配器；跨域后端需允许实际 Pages 来源的 CORS 请求。**API 密钥必须留在后端，不要写入 HTML、JavaScript、GitHub 仓库或浏览器存储。** GitHub Pages 不能运行后端，也不能安全保管模型密钥。

## 测试

安装测试开发依赖（网站本身不需要这一步）：

```bash
npm ci
npx playwright install chromium
```

在一个终端从项目根目录启动静态服务器，在另一个终端运行：

```bash
npm run check
npm test
git diff --check
```

默认测试站点为 `http://127.0.0.1:8000`，用 `TEST_BASE_URL` 覆盖，可测试 Pages 子路径。

在 Linux 云端已有系统 Chromium 时，可使用：

```bash
CHROMIUM_PATH=/usr/bin/chromium npm test
```

`PLAYWRIGHT_MODULE` 可指向环境已有的 Playwright 模块，避免重复安装；一般开发者不需要设置它。自动测试使用隔离的浏览器上下文，不会删除日常浏览器数据；测试会创建并清除测试上下文中的记录。

覆盖：工具搜索/分类/收藏与持久化、两个 AI 表单及请求 JSON、无模拟 AI 调用、盈利/亏损/100% 费率/零成本/小数/非法输入、CSV、文本所有转换/TXT、提示词 CRUD/筛选/导入导出/非法 JSON/防脚本注入、剪贴板、资料、确认及取消清除、本地存储被禁用、所有页面路由/链接，以及 320、375、720、768、1024、1440px 布局与移动导航。

自动测试验证内部链接目标和 GitHub 外链的地址结构；GitHub 外部服务及公开 Pages 的可达性需在允许访问这些域名的网络中另行确认。
